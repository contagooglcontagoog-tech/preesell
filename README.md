# Preesell - Verificação Anti-Robô

Página de presell / verificação de segurança (Anti-Bot Check) com redirecionamento automático após confirmação.

## Funcionalidades
- Caixas de marcação interativa "Não sou um robô".
- Aguarda 2 segundos após a marcação da caixa para redirecionar.
- Redireciona exclusivamente para `https://popozuda-lisinha.vercel.app/products/lisinha?variant=48843070963939`.
- Preserva parâmetros de rastreamento de anúncios (UTM, gclid, etc.).
